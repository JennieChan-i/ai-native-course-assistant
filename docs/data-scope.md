# 数据范围与简历口径

| 数据或说法 | 当前可核验范围 | 对外说明 |
|---|---|---|
| 公开仓库 | 17 条重新撰写的演示片段，14 个主题 | 可从本仓库重新构建向量索引 |
| 作者本机正式库 | 14 份课程、877 条切片、545,288 个正文字符 | 对应独立的完整库版本，不在公开仓库分发 |
| “70 万+字符、900+ chunk” | 历史项目描述；当前留存的正式库不能直接证明这两个数 | 面试中明确是历史处理阶段口径；若需证明应补原始文稿与版本记录 |
| 历史检索测试 | 100 条内部同源问题、Top-5，文稿 91%、主题 92%、源片段 59% | 指检索命中，不是回答准确率；逐题课程材料未公开 |
| 公开示例测试 | 14 条针对示例片段的问题 | 可在网页重跑；不预设命中率 |
| Badcase 页面案例 | 六个有明确“模拟”标识的场景 | 用于解释诊断与修复方法，不计为真实用户反馈 |
| 当前模型 | `.env.example` 为 qwen3.8-flash；可由使用者修改 | 历史 qwen-flash 与当前展示配置分别表述 |

本地用户会话、PRD、简历文本和反馈保存在忽略的 SQLite 文件中。项目没有公开真实用户规模、业务增长或未经校准的答案准确率。
